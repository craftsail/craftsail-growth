# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the
work. Harassment and personal attacks are not tolerated.

Report unacceptable behavior to askuygo@foxmail.com. Reports are handled
confidentially, and maintainers may remove comments, commits or contributors
that violate the code.
