# 数据库验收

2026-10-09 已在 SQLite 与真实 MySQL 8.0.39 上通过以下关键路径。MySQL 测试库使用 `utf8mb4_unicode_ci`，故意保留默认不区分大小写的排序规则，以发现精确标识符的差异。

## 运行

```sh
make test-mysql
```

需要 Go、Python 3 与可访问的 Docker。首次运行可能拉取 `mysql:8.0.39`。脚本仅在回环地址开放随机端口，不挂载业务目录；使用随机凭据和随机库名。完成、失败或收到 SIGTERM / Ctrl-C 后清理本次容器及匿名卷，凭据文件随临时目录删除。强制终止进程或 Docker 不可用可能阻止清理，此时按脚本输出的容器名检查。

测试其他 MySQL 8 镜像：

```sh
python3 scripts/test-mysql.py --image mysql:8.0.39
```

也可通过 `CRAFTSAIL_TEST_MYSQL_DSN` 环境变量连接专用测试服务器并运行 `go test ./internal/integration -count=1 -v`。DSN 必须不含数据库名，账号需有创建和删除测试库的权限；测试只创建、迁移和删除自身随机生成的 `craftsail_accept_*` 库。不要将密码写入仓库。未设置该变量时，普通 `go test ./...` 运行 SQLite 部分，明确跳过 MySQL 部分；CI 通过 `make test-mysql` 补齐。

## 已通过的场景

| 场景 | 验收内容 |
| --- | --- |
| 迁移 | 新库、重复执行、旧 `uk_sample` 升级为版本唯一索引、同日新版本并存、保留手工回答 |
| Google 同步 | 完整批次替换、旧 token 写入与结束拒绝、真实 INSERT 失败后的事实和覆盖回滚、空成功批次、跨项目隔离 |
| 分析 | 指定事件精确匹配、下划线字面搜索、筛选早于分页、完整导出、大小写 URL 分组及精确下钻、页面候选不合并 |
| 共享配额 | 24 个并发请求只允许 5 次、持久计数、较短退避不覆盖较长退避、接口族隔离、跨日重置 |
| 索引 | 成功后检查失败保留成功证据、多来源重发现保留时间、项目与资源隔离、历史插入失败回滚最新状态 |
| 观察与周报 | 基线 JSON 和固定窗口持久化、追加结果历史、上线不自动完成任务、项目隔离、UTC+8 同日重复周报只更新一份 |

MySQL 实测暴露并修复了事件名大小写筛选问题：选择 `sign_up` 不再匹配 `Sign_Up`。两者可以同时存储、分别分析。

- 生产历史备份的升级、超大数据量与多服务进程压力测试。本轮迁移验收包含明确构造的旧索引，不代表所有历史 schema 都已覆盖。
- 真人首次价值耗时、买家措辞访谈与真实 28 天效果观察。这些不能用数据库夹具替代。
